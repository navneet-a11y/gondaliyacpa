All five returns stay outstanding and each year is filed separately. A T2 is due within six months of each fiscal year-end, so five missed year-ends means five separate returns, every one of them still required. Filing all five at once is routine and closes the years in a single pass.

A true nil return carries no percentage late-filing penalty, because that penalty is a percentage of tax owing and the corporation owes $0.00. The unfiled year still stays open forever, invites a demand to file and an arbitrary assessment, blocks a clearance certificate and dissolution, and costs a non-resident-owned corporation $25.00 per day up to $2,500.00.

Each year is a separate return with its own fiscal year-end and its own due date. There is no combined five-year return and no reduced rate for filing several years together.
