Nil T2 filing in Canada › How Do I Fix a Nil T2 Return I Filed With the Wrong Year-End?

A return filed for the wrong period is corrected by filing for the correct period, because the fiscal year dates are what define which year a return covers. A fiscal year-end already on record cannot be moved without the Canada Revenue Agency agreeing to the change. Which route applies depends on what was assessed.

SituationWhat it needs
Return filed for a period the corporation did not haveA return for the correct period
Fiscal year-end recorded incorrectlyThe agreement of the Canada Revenue Agency to change it
Figures wrong, period rightAn adjustment to the return as filed
Year already assessedThe correction is handled against that assessment

A true nil return carries no percentage late-filing penalty, because that penalty is a percentage of tax owing and the corporation owes $0.00. The unfiled year still stays open forever, invites a demand to file and an arbitrary assessment, blocks a clearance certificate and dissolution, and costs a non-resident-owned corporation $25.00 per day up to $2,500.00.
