Nil T2 filing in Canada › What Happens if I Don't Respond to a CRA Demand to File a T2?

The Canada Revenue Agency can assess the corporation arbitrarily, without waiting for the return. A demand to file is a formal request, and the return remains due within six months of the fiscal year-end regardless. Filing the real return replaces an arbitrary assessment with the corporation's actual figures.

A true nil return carries no percentage late-filing penalty, because that penalty is a percentage of tax owing and the corporation owes $0.00. The unfiled year still stays open forever, invites a demand to file and an arbitrary assessment, blocks a clearance certificate and dissolution, and costs a non-resident-owned corporation $25.00 per day up to $2,500.00.

An arbitrary assessment is the Agency assessing on its own figures because no return was filed. It does not close the year in the way a filed return does, and it is replaced once the real return is assessed.
