Nil T2 filing in Canada › What Happens if I Don't File a Nil T2 for a Numbered Company?

Nothing changes because the corporation has a number instead of a name. A numbered company is an ordinary corporation and must file a T2 within six months of each fiscal year-end until it is dissolved. The numbered name affects nothing about the filing obligation or the due date.

A true nil return carries no percentage late-filing penalty, because that penalty is a percentage of tax owing and the corporation owes $0.00. The unfiled year still stays open forever, invites a demand to file and an arbitrary assessment, blocks a clearance certificate and dissolution, and costs a non-resident-owned corporation $25.00 per day up to $2,500.00.

Many holding and shelf corporations are numbered. The Canada Revenue Agency identifies the corporation by its business number rather than its name, so a numbered company's return is filed exactly like any other.
