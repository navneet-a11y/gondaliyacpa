Four Years Is Usually When the Letter Arrives

A demand to file names the tax years the Canada Revenue Agency wants and sets a date. It is not a reminder and it is not the start of a conversation. The important thing about it is what the Agency may do if the date passes, which is to assess the corporation itself, without the return, on figures of its own choosing. That is an arbitrary assessment.

An arbitrary assessment on a corporation that genuinely had no activity is the worst outcome available here, because it creates a tax debt out of an estimate for a year in which nothing happened. Reversing it means filing the actual return anyway and then getting the assessment adjusted, which is the same work plus an argument. Filing before the date on the letter avoids the whole sequence.

If a demand has already arrived, it does not change what gets filed. It changes the order of urgency: the years the letter names go first, and the rest of the series follows immediately behind so the account closes rather than partially closes.

A demand to file is also not the only letter that arrives. A request to file is softer, carries no assessment power, and is easy to mistake for the demand. The difference worth knowing is that only the demand carries the arbitrary assessment behind it, so the letter should be read for what it actually threatens rather than filed with the rest of the post.

The three first-year rules. The first tax year cannot exceed 53 weeks and the year-end must match CRA's record or the transmission is rejected. Schedule 24, the first-time filer schedule, is required on the first T2 a corporation ever files. The year-end you report is the one the Canada Revenue Agency holds on file, so a different date on the return is refused rather than corrected.

The Order It Happens In

  1. Read any letter from the Agency and establish whether it is a request to file or a demand to file.
  2. File the years a demand names first, and before the date it sets.
  3. Confirm the year-end on file and that all four years were nil.
  4. Complete Schedule 24 on the earliest return, which is the only one that carries it.
  5. Prepare the nil GIFI schedules for each year: Schedule 100, Schedule 125 and Schedule 141.
  6. Sign Form T183CORP for each of the four tax years.
  7. Transmit the remaining years immediately behind the demanded ones, so the account closes rather than partly closes.
